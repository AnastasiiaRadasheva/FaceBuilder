# Photorobot – Face Builder in Python

A desktop app for building a cartoon face from parts: eyes, nose, mouth, hair and accessories.
Click a button to cycle through the options for each part, then save the finished face as a PNG.

## Tech

Python, CustomTkinter, Tkinter Canvas, Pillow (layering images with alpha compositing).

## Run

```bash
pip install customtkinter pillow pygame
python fotorobot.py
```

Saved faces go to the `output/` folder.
